Frequently asked questions

Can I move a project from the free version?

Yes. PRO uses the same markup, Sass variables and JavaScript modules, so pages built on the free version carry over and you add the PRO pages and components you need.

Is it a one-time payment?

Yes. You pay once, use the code in your product for as long as you like and get every update.

Is support included?

Every license comes with premium email support; how long depends on the license.

Does it work with my back end?

Yes. The build is plain HTML, CSS and JavaScript, so it works with Laravel, Rails, ASP.NET, Django or any other stack.

Can I get a refund?

Within 30 days of purchase. Email info@adminkit.io.
