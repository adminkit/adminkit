# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Dark mode with Bootstrap 5.3 color modes: `data-bs-theme="dark"` on `<html>` switches `css/app.css` to the dark palette without reloading; an inline script in `<head>` sets the stored mode (light, dark or auto, which follows the operating system) before the first paint
- Color mode toggle (Light / Dark / Auto) in the navbar
- Motion tokens: `$ak-transition-duration-fast|base|slow` and `$ak-transition-easing-standard|emphasized`, exposed as `--ak-duration-*` and `--ak-ease-*`; Bootstrap's fade and collapse transitions, the dropdowns and the sidebar use them
- Cards fade up as they scroll into view, staggered (`.ak-reveal-cards` on `<main>`, `.ak-reveal` on any element); the footer fades in with them. Copy the reveal script from `src/partials/site-meta.hbs` into your `<head>` along with the color mode script
- `data-count-up` counts a number up from zero when it scrolls into view; the stat cards use it
- Skeleton placeholders (`.ak-skeleton`, the `skeleton` partial) on the dashboard charts and map, cleared by `adminkit.chartjs()`, `adminkit.vectorMap()` or `adminkit.ready(element)`, which fire `adminkit:ready`
- Clickable cards (`a.card`, cards with a `.stretched-link`) lift on hover and keyboard focus
- Everything animated respects `prefers-reduced-motion: reduce`: no movement, at most a fade; charts draw without their entrance animation
- WCAG 2.2 AA in both color modes, checked with axe on every page; `ak-readable()` and `$theme-text-colors`/`$theme-text-colors-dark` keep text colors readable
- 404 and 500 error pages, an Alerts page (default, icon, outline and colored outline alerts), a Modals page (default, colored, centered and sized dialogs) and a Tables page (basic, striped, condensed, hoverable, bordered, contextual and responsive tables), ported from AdminKit PRO and linked from the sidebar; `css/app.css` now holds Bootstrap's alert and modal styles with the `.alert-outline`, `.alert-outline-coloured`, `.alert-icon` and `.modal-colored` variants
- `src/data/stats.json`, generated by `npm run stats` (and by the build) from the pages, `src/data/plugins.json`, the icon list, `src/data/appearance.json` and `src/data/comparison.json`: the page, dashboard, plugin and icon counts the templates and the README show; `npm run lint` fails while it or the README table is stale, or while a dependency is neither a listed plugin nor an explained exception
- `src/data/editions/pro.json`, a committed snapshot of AdminKit PRO's `stats.json`, refreshed with `npm run stats:sync -- --pro <checkout>`
- `npm run screenshots`, run on demand, captures the AdminKit PRO screenshots for the upgrade page and the dashboard screenshots for the README with Playwright and sharp

### Changed

- The dashboard (`index.html`) becomes the Analytics dashboard, also in the sidebar and the page title: visitors, page views, bounce rate and session duration, monthly visitors, traffic sources, real-time visitors and a top pages table replace the sales, earnings and orders widgets and the projects table, and the browser usage chart lists Edge instead of IE
- Darken the theme colors to reach 4.5:1 contrast: primary `#266ed8` (was `#3b7ddd`), success `#138161`, info `#127d8e`, danger `#da2839`, gray-600/secondary `#6a737a`; warning keeps its yellow with dark text; card titles, secondary text and sidebar links follow
- Bundle Inter from `@fontsource/inter` with `font-display: optional` (preloaded by the built pages) instead of loading it from Google Fonts; `dist/fonts` holds the files
- Replace the deprecated `.text-muted` with `.text-body-secondary`
- Card titles are `h2`, card subtitles paragraphs, so headings no longer skip levels; icon-only controls have accessible names, links that act as buttons have `role="button"`, and keyboard focus stays visible on the sidebar and navbar links
- The footer year and the `css/app.css` banner come from the build year and the `package.json` version
- Stat card numbers use `,` thousands separators
- Require Node 24 (`.nvmrc`, `engines`)
- Enforce Conventional Commits with commitlint and lefthook git hooks
- Replace ESLint 8 and babel-eslint with ESLint 9 flat config, add Prettier and `.editorconfig`
- Add GitHub Actions CI: lint, build and commitlint on pull requests and pushes to `main`
- Track `package-lock.json`
- Remove the committed Google Maps API key. The Google Maps page loads the Maps JavaScript API without a key (`callback=initMaps&loading=async`), which Google draws for development only; add your own key, restricted by HTTP referrer, for production (see `src/scripts/a-maps-google.hbs`)
- Replace webpack and Babel with a Vite 8 multi-page build and move the page sources from the separate adminkit-builder repo into `src/pages`, `src/layouts`, `src/partials` and `src/scripts`; images move to `public/img`
- Stop tracking the generated `static/` output; `npm run build` writes `dist/`, which Vercel, npm publishing and the GitHub release workflow build
- The demo pages load `js/app.js` with `<script type="module">`; the published `js/app.js` keeps working with a plain `<script src>` (npm and CDN), its code wrapped in a function scope so the only globals it adds are `window.bootstrap`, `window.lucide`, `window.theme`, `window.adminkit`, `window.Chart`, `window.jsVectorMap` and `window.VanillaCalendar` (plus `window.uidEvent`, which Bootstrap's event handler stores on `window` when it listens to window events)
- Attach a zip of the built template to GitHub releases on `v*` tags
- Upgrade Chart.js to 4 and rewrite the chart configs for its options API; bars get rounded tops
- Upgrade SimpleBar to 6
- Replace flatpickr with Vanilla Calendar Pro for the dashboard calendar
- Target the browsers Vite compiles for (Chrome and Edge 111, Firefox 114, Safari and iOS 16.4) and hash font and image assets
- Upgrade ESLint to 10
- Replace Feather icons with Lucide: markup uses `data-lucide` with Lucide's canonical names, the `.feather`, `.feather-sm` and `.feather-lg` classes become `.lucide`, `.lucide-sm` and `.lucide-lg`, and `js/app.js` only bundles the icons the templates use (`window.lucide.createIcons()` replaces `window.feather.replace()`)
- Rename the Feather icons page to Lucide (`icons-lucide.html`), searchable by name and tag; `icons-feather.html` redirects to it
- Components take their mode-dependent colors from custom properties: `--bs-gray-*` (which turn around in dark mode) and `--ak-surface-bg`
- Build `window.theme` from the CSS custom properties of the current color mode; it keeps its keys, adds `id`, `name`, `body-bg`, `body-color` and `border-color`, and `document` fires `adminkit:themechange` when the mode changes
- Create the charts and the world map with `adminkit.chartjs()` and `adminkit.vectorMap()`, which recolor them when the color mode changes; the dashboard calendar follows the mode too
- Tables placed directly in a card line up with the card padding, and `.table-action` styles the edit and delete links in a table
- Redesign the Upgrade to Pro page: a comparison table generated from the AdminKit and AdminKit PRO stats, screenshots of AdminKit PRO in the active color mode, and a link to the pricing
- The Lucide page's meta description quotes the generated icon count; the color mode toggle takes the modes from `src/data/appearance.json`
- Rewrite the README: generated feature table, screenshots, a one-command start, npm and CDN usage and the framework guides
- Below the lg breakpoint the sidebar is a Bootstrap offcanvas sheet (`.offcanvas-lg`, so `css/app.css` now includes Bootstrap's offcanvas styles): the navbar toggle opens it over a backdrop; Escape, the backdrop and following a link close it, focus stays inside and returns to the toggle, and the page does not scroll behind it. From lg up the toggle hides and shows the sidebar as before. The toggle is named for its action (Collapse sidebar / Expand sidebar) and has `aria-expanded`

### Removed

- The unused `unsplash-3.jpg` photo and the IE-only CSS
- feather-icons

### Fixed

- Button contrast in both color modes: `.btn-dark` has dark text in dark mode, and every `.btn-outline-*` (including `light` and `dark`) draws its label and border in a color that reaches 4.5:1 on the page and card backgrounds
- Dropdown carets are drawn by one `chevron()` mixin that centres the visible V on its box, and the inline carets sit on the middle of the text
- `npm ci` no longer fails without a `.git` directory (Vercel CLI deploys, tarballs, Docker builds): the `prepare` script is gone and lefthook's own `postinstall` installs the git hooks, skipping CI
